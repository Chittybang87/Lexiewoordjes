# Lexie Woordjes

Een speels Nederlandstalig letterspel voor kleuters. Help Lexie met opdrachten (keuken, winkel, post, park) en maak korte woordjes door letters te kiezen.

## Starten

```bash
npm install
npm run dev
```

Open daarna de URL in de browser (het beste op een tablet).

## Installeren op tablet of telefoon

De app is een **Progressive Web App (PWA)**: je kunt hem als icoontje op het startscherm zetten, net als een echte app.

De site moet via **HTTPS** bereikbaar zijn (of lokaal via `localhost`).

### Android (Chrome)

1. Open de website in Chrome
2. Tik op ⋮ (menu) → **App installeren** / **Toevoegen aan startscherm**
3. Bevestig — Lexie verschijnt als icoon op je startscherm

### iPhone / iPad (Safari)

1. Open de website in Safari
2. Tik op Deel (□↑)
3. Kies **Zet op beginscherm**
4. Tik op **Voeg toe**

Daarna start de app fullscreen, zonder browserbalk.

## Spelen

1. Kies een niveau (Makkelijk / Gewoon / Lastig)
2. Lexie krijgt een opdracht
3. Tik de juiste letters aan om het woordje te maken
4. Verzamel sterren en ga door naar de volgende opdracht
