# Lexie Woordjes

Een speels Nederlandstalig letterspel voor kleuters. Help Lexie met opdrachten (keuken, winkel, post, park) en maak korte woordjes door letters te kiezen.

## Starten

```bash
npm install
npm run dev
```

Open daarna de URL in de browser (het beste op een tablet).

## Spelen

1. Kies een niveau (Makkelijk / Gewoon / Lastig)
2. Lexie krijgt een opdracht
3. Tik de juiste letters aan om het woordje te maken
4. Verzamel sterren en ga door naar de volgende opdracht
